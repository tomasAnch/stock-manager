# Alertas y reposición

Implementará las consultas de RF-10 a RF-12: productos activos por debajo del mínimo y, para el dueño, cantidades sugeridas agrupadas por proveedor. La sugerencia será stock objetivo menos stock actual.

Solo leerá el inventario. No guardará alertas ni órdenes, no reservará stock ni registrará compras. El frontend mantendrá las ediciones temporales y generará las salidas de texto y CSV con los datos autorizados.
