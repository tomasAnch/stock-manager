# Acceso y permisos

Implementará RF-01 y RF-02: login, validación del token y autorización por rol y comercio. En cada solicitud protegida consultará al usuario para comprobar que sigue activo y obtener su rol y comercio actuales.

Entregará ese contexto a los demás módulos. No incluirá registro público, recuperación de contraseña ni ABM de usuarios.
