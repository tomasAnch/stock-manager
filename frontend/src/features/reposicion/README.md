# Alertas y reposición

Mostrará faltantes para ambos roles. El dueño podrá generar la lista por proveedor, editar cantidades, omitir productos y copiar texto o descargar un CSV.

Ambas salidas usarán los mismos ítems editados. La lista no se guardará en la base; al recargar o recalcular se perderán las ediciones. El CSV conservará la fecha del cálculo y respetará el formato definido en RN-14: UTF-8 con BOM, separador `;`, coma decimal y campos escapados.
