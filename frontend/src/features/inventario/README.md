# Inventario

Mostrará el formulario de ingresos y egresos, los ajustes para el dueño y el historial por producto. Indicará la unidad y validará cantidades para facilitar la carga; el backend volverá a comprobarlas.

Deshabilitará el envío mientras una operación esté pendiente y mostrará confirmación solo tras una respuesta exitosa. Las cantidades de la API llegarán como cadenas decimales.

Estado: carpeta creada; componentes y conexión con la API pendientes. Corresponde a RF-07 a RF-09 de [requerimientos](../../../../docs/segunda_entrega/01-requerimientos.md).
